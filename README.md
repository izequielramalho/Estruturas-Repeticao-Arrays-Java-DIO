# Estruturas de Repetição e Arrays - DIO Orange Tech+

Repositório criado durante o bootcamp Orange Tech+ Backend da DIO,
documentando meu aprendizado sobre estruturas de repetição e arrays em Java.

## Conteúdo

- **For** → repetição com número fixo de vezes
- **While** → repetição enquanto condição for verdadeira
- **Do While** → repetição que executa pelo menos uma vez
- **For Each** → repetição para percorrer listas e arrays
- **Arrays** → estrutura para armazenar múltiplos valores

## Tecnologias

- Java 17
- IntelliJ IDEA
- Git e GitHub
